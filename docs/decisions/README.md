# Decision records

Each significant, hard-to-reverse decision gets a numbered record here, so a future
contributor, human or AI, can see *why* things are the way they are without
re-litigating settled questions.

- A significant change lands **with its record in the same pull request**.
- Records are history: to reverse one, write a new record that supersedes it and link
  the two. Never edit an old record's decision.
- Keep each record to a page or less.
- Format: [MADR](https://adr.github.io/madr/), file name `NNNN-short-title.md`, with
  front matter for status, date and roles (never personal names).

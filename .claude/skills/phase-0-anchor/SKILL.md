# Phase 0: Anchor the task

Analysis only: no file changes, no branch, no commits.

1. Understand the task. Read the issue, the owners in the "Where each truth lives"
   table in `AGENTS.md` that the task touches, and the related decisions in
   `docs/decisions/`.
2. Find what is unclear, the risks and the hidden assumptions. Challenge weak ideas and
   propose better ones when there are any.
3. If the work is too large for one coherent pull request, split it into smaller pieces
   and propose the order.
4. Present your reading: scope, what is left out, open questions and your proposed
   answers. Then **wait for confirmation**.

Ask questions so they can be answered with one word, with a recommendation marked.
